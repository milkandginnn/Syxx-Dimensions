UX Principles
· Tri-state verdict — SECURE / TAMPERED / INCONCLUSIVE; degraded never collapses to SECURE
· Network Key State ambient in inspector at all times
· Record-type toolbar includes AAAA — AAAA tampering independently checkable
· Full provenance: XID, transport, RCODE, resolver IP all surfaced
· Vantage timeout visible inline; replacement resolver addable immediately
· DNSSEC note is honest about presence-only; A2 proposal surfaced to user
· Destructive action (Clear) last, styled red, visually separate
Accessibility
· Colour never sole signal — every status has a text label
· VoiceOver: sidebar items aria-current="page", role=button
· Verdict banner meets WCAG AA contrast on dark background
· DNS table uses semantic <table> with th scope="col"
· ⌘R runs investigation; Tab order: toolbar → inputs → results
· prefers-reduced-motion: pulse dot suppressed, no layout animations
· Dynamic Type: SwiftUI implementation uses pt sizing
