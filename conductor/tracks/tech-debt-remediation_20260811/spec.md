## Summary

## Context

Syxx is a cross-platform DNS tampering detection tool shipping on macOS (SwiftUI), Windows (WinUI 3), Linux (Avalonia), and a Python server. The codebase has grown to ~167K LOC across 675 source files. A 2026-08-10 analysis identified medium-high debt: a 3,730-line god file (`app.py`), 69 over-long functions, 13 quarantined synthesis tests, 14 untested server modules, ~1,900 LOC of cross-platform duplication, outdated Sentry SDKs on all 3 platforms, and infrastructure gaps (no containerization, no rollback procedures).

This track addresses the full remediation roadmap before the next major feature push.

## Risk Mitigations

| Risk | Mitigation |
|---|---|
| `app.py` decomposition breaks live routes | Extract incrementally; run full test suite after each module extraction; keep original as fallback until verified |
| Sentry major upgrades break telemetry | Pin to latest minor first, read migration guide, update one platform at a time, verify spans export |
| Quarantined tests reveal real synthesis bugs | Triage each failure as "stale test" vs "real bug" before fixing; file separate bug tracks for real defects |
| Shared .NET library diverges during extraction | Extract common interfaces first, verify both platforms compile, then consolidate implementations |
| Large track stalls mid-progress | Each phase is independently valuable; phases can be completed and committed separately |
