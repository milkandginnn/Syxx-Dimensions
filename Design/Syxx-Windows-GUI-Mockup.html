UX Principles (Windows-specific)
· WinUI InfoBar for verdict — dismissible, semantically typed (Warning / Error / Informational)
· NavigationView with top-level search box (Fluent pattern)
· Breadcrumb replaces page titles — always shows position in hierarchy
· CommandBar with AppBarButton icons; primary action right-aligned
· ContentDialog for Witness Sign (modal, keyboard-trapped)
· Cages requires Administrator — UAC badge shown in nav + header
· Cascadia Code for monospace; matches Windows Terminal aesthetic
· No macOS-specific affordances (no ⌘, no Dock, no menu bar)
Parity with macOS Build
· Same 10 views, same feature surface
· Identical tri-state verdict logic — SECURE / TAMPERED / INCONCLUSIVE
· Same brand palette (#E8F53C / #8C5CF5 / #C7A9FF)
· Same inspector data: XID, transport, RCODE, resolver, provenance
· Same DNSSEC honest note about presence-only (A2 proposal)
· Process attribution shows Authenticode (Windows) vs. SecStaticCode (macOS)
· "admin" badge replaces "sudo" badge for Cages
